# Gaisan 0.1.0

A macOS menu bar for an API-price estimate of local Claude, Codex, Grok, and Pi logs. Not a bill. The ticker is today plus the amount.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Gaisan in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/gaisan/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Gaisan-0.1.0-macOS-apple-silicon.zip`
- **Intel:** `Gaisan-0.1.0-macOS-intel.zip`

Unzip it and move `Gaisan.app` to Applications. Quit the previous copy before replacing it. Open Gaisan and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Today ticker.** The menu bar shows `today` and today's estimate. It updates when the local usage cache changes.
- **Dashboard.** Click the ticker for Today / 7d / 30d / All, a stacked history chart, source mix, cache savings, and top models.
- **Cache-aware prices.** Uncached input, cache reads, cache writes, and output are priced separately. A provider-reported cost on a row wins over list price.
- **Fast open.** A local snapshot means the panel does not wait on a cold parse of the usage cache.

## Validation

- `swift test`: 8 tests in 1 suite passed, including cache-aware prices, idle Grok rows, and snapshot reuse.

- `swift format lint --strict --recursive Sources Tests Package.swift` passed.

## Compatibility

No account sign-in. Gaisan reads local session logs and the usage scan cache already on this Mac. Remaining plan quota stays in Uso.
