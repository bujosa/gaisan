# Gaisan 0.2.0

Today’s ticker follows the local Claude and Codex session logs. It no longer waits for a stale usage-scan cache to move.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Gaisan in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/gaisan/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Gaisan-0.2.0-macOS-apple-silicon.zip`
- **Intel:** `Gaisan-0.2.0-macOS-intel.zip`

Unzip it and move `Gaisan.app` to Applications. Quit the previous copy before replacing it. Open Gaisan and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Live today.** The menu bar reads Claude `~/.claude/projects` jsonl and Codex `token_usage_record` lines as they land. FSEvents plus a 20-second backup timer. A frozen usage-scan cache no longer pins today at $0 after midnight.
- **History stays cached.** 7d / 30d / All still fold the usage-scan cache when it is present. That fold is snapshotted separately so a new log line does not re-parse 50 MB.
- **Safe file walk.** Codex is read from the current day’s session folder and recent continuing sessions, not from multi-gigabyte rollouts whose mtime was touched today.

## Validation

- `swift test`: 12 tests in 1 suite passed, including live Claude/Codex parsing, cache-aware prices, idle Grok rows, and snapshot reuse.
- Live `--print` on this Mac after the log reader: today, 7-day, 30-day, and all-time totals, with Claude and Codex on today.
- `swift format lint --strict --recursive Sources Tests Package.swift` passed.

## Compatibility

No account sign-in. Remaining plan quota stays in Uso. Grok and Pi still come from the historical cache when it exists; today’s live mix is Claude and Codex.
