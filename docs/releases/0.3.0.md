# Gaisan 0.3.0

A Yday tab, All that keeps growing, and every Codex session counted. Codex was undercounted by up to half.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Gaisan in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/gaisan/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Gaisan-0.3.0-macOS-apple-silicon.zip`
- **Intel:** `Gaisan-0.3.0-macOS-intel.zip`

Unzip it and move `Gaisan.app` to Applications. Quit the previous copy before replacing it. Open Gaisan and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Yday.** A yesterday tab with its own hourly chart: Today · Yday · 7d · 30d · All.
- **All keeps growing.** All, 7d, and 30d add the live Claude and Codex logs written after the usage-scan cache, instead of stopping at the cached total.
- **Every Codex session counts.** A Codex session keeps writing to the day folder it started in, and long-lived sessions stay open for weeks. Gaisan read only recent folders and missed their usage. On Nov 1 it saw 9.0k of 15.5k token records, so Codex showed $278 instead of $520.
- **Fast with huge logs.** Gaisan remembers how far it read each log and parses only what was appended. Multi-gigabyte sessions stay cheap:
  - Cold rebuild: about 9 s, down from 65 s.
  - Refresh: about 0.6 s.
- **Claude one-hour cache writes** are priced at their own rate (2× input), not the five-minute rate.
- **Without the T3 usage cache,** the live logs cover the last 30 days, and All grows from there. Before, they covered only today.

## Validation

- `swift test`: 17 tests passed. They cover:
  - Yesterday kept separate from today.
  - A Codex session in an older day folder.
  - Appended-only reads, including an unfinished last line.
  - Shrunk logs.
  - One-hour cache pricing.
- `swift format lint --strict` passed. CI passed on the pull request.
- Live, Nov 1:
  - Claude: $116 (ccusage 20.0.48: $116.6).
  - Codex token counts match the raw logs and ccusage exactly. ccusage prices gpt-6.1-sol higher; Gaisan uses the T3 rate table.

## Compatibility

The first launch rebuilds `~/Library/Caches/Gaisan/ledger.json` once. Sessions that span the cache boundary can still be counted on both sides.
